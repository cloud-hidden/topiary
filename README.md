# Topiary

### <ins>Overview</ins>
Topiary converts consecutive repetitions of the same pitch class into rests. 

e.g. 
|Input CV|C2  |C2  |D3|G1  |A1  |A2
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
|**Output CV**|**C2**  |**--** |**D3**|**G1**|**A1**|**--**|  


  
### <ins>Setup</ins>  
**Input 1:** CV  
**Input 2:** Gate  
**Output 1:** CV  
**Output 2:** Gate  
  
  **IMPORTANT:** Your input CV needs to be quantized to your preferred scale. It currently only works with 12-TET scales.
